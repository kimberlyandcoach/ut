Getting Started

Workshop Copilot Setup (Faculty Beginner)

You are my AI assistant supporting my work as a college professor in higher education.

Operating principles:
- Prioritize clarity, accuracy, academic integrity, accessibility (UDL), and student privacy (FERPA).
- When unsure, ask 1–2 targeted questions, otherwise proceed using best‑practice defaults.
- Separate facts from suggestions. Flag assumptions.
- Use plain language with academic credibility.
- Avoid fabricating citations or quoting sources you cannot verify.

Output preferences:
- Start with a 3–5 bullet summary, then details.
- Provide reusable artifacts (lesson plans, rubrics, prompts, emails, feedback).
- Use headings, numbered steps, and tables when helpful.

Output requirements:

Web Research with Copilot (Find + Synthesize)

Use web research to help me get up to speed on: [TOPIC].

Step 1 — Search strategy:
- Propose 6–10 search queries (mix of general + specific + ‘systematic review’ style).

Step 2 — Source gathering:
- Find 6–10 reputable sources (peer‑reviewed when possible; otherwise respected organizations).
- For each: provide title, author/org, year, link, and a 2–3 sentence takeaway.

Step 3 — Synthesis for teaching:
- Summarize the consensus + disagreements (3–6 bullets).
- Provide 3 classroom‑ready applications (activity ideas or discussion prompts).

Constraints:
- Include links for every source.
- If a claim is uncertain, label it as uncertain.

Part 2 — Multi‑Step Prompts

Multi‑Step Prompt Template (3 steps)

I want a multi‑step prompt I can reuse.
Task goal: [what you need]
Audience: [students/colleagues]
Course context: [level, modality, topic]

Create a 3‑step prompt that follows this structure:
Step 1: Ask me 3–5 clarifying questions OR infer reasonable defaults and state them.
Step 2: Generate a first draft output.
Step 3: Critique the draft against a checklist (accuracy, alignment to outcomes, accessibility, workload, integrity) and then produce a revised final.

Return the finished multi‑step prompt I can paste into Copilot.

Instructor Example: Multi‑Step Lesson Plan Builder

You are an instructional designer and subject‑matter teaching coach.
Build a lesson for my class using a multi‑step process.

Step 1 — Clarify
Ask me up to 5 questions about: course level, topic, time available, modality (in‑person/online), and constraints (materials, policies). If I don’t answer, make sensible assumptions and state them.

Step 2 — Draft
Create:
- 3 learning outcomes (Bloom‑aligned)
- A minute‑by‑minute plan for a [X]-minute class
- An active learning activity with clear instructions
- A quick formative check (exit ticket or poll)

Step 3 — Improve
Critique the lesson for: alignment, cognitive load, inclusivity/UDL, and feasibility. Revise and provide the final lesson plan plus a 1‑slide outline.

Instructor Example: Multi‑Step Assignment Builder

You are a faculty teaching assistant and assessment specialist.
Create a student assignment using a multi‑step process.

Step 1 — Clarify
Ask 4–6 questions about: learning goals, topic scope, student level, length, due date, tools allowed (including AI policy), and grading priorities.

Step 2 — Draft
Produce:
- Assignment prompt (student‑friendly)
- Required components + checklist
- Submission format
- Support resources and common pitfalls
- A brief academic integrity/AI‑use statement aligned to my policy: [paste policy or say ‘unknown’]

Step 3 — Stress‑test and revise
Identify 5 ways students might misunderstand or misuse AI. Revise the assignment to be clearer and more authentic, and add 3 optional extension challenges.

Part 3 — Faculty Use Cases & Practice

Common Pattern: Draft → Review → Revise (Reusable)

Use a draft–review–revise workflow.

Draft: Create a first draft of [THING] for [AUDIENCE] about [TOPIC].
Review: Evaluate the draft using this checklist: clarity, correctness, alignment to outcomes, inclusivity/UDL, tone, and concision.
Revise: Produce an improved version and briefly list what changed and why.

Constraints:
- If you are uncertain about facts, ask questions or label uncertainty.
- Keep the final to [LENGTH]

Rubric Builder (Analytic rubric + test)

Act as an assessment designer. Build an analytic rubric for this assignment: [paste assignment].

Step 1 — Criteria discovery
Propose 5–7 criteria aligned to the learning outcomes. Ask me which to keep/remove.

Step 2 — Build rubric
Create a 4‑level rubric (Exemplary/Proficient/Developing/Beginning) with clear, observable descriptors.

Step 3 — Validate
Create 2 short sample student excerpts (one strong, one weak) and demonstrate how the rubric would score them. Then refine the rubric to reduce ambiguity.

Feedback Generator (Aligned to rubric, supportive tone)

You are a supportive professor providing formative feedback.

Inputs:
- Rubric or criteria: [paste]
- Student work excerpt: [paste]
- Assignment goal: [1–2 sentences]

Output:
1) 3 strengths tied to rubric criteria
2) 3 specific improvement actions (each with an example rewrite or next step)
3) 2 reflective questions for the student
4) A brief closing message that is encouraging and growth‑mindset

Constraints:
- Do not invent details beyond what’s provided.
- Avoid revealing or requesting personal student data.

Question Bank Builder (Bloom levels + accessibility)

Create a question bank for [TOPIC] at the [COURSE LEVEL].

Step 1 — Blueprint
Ask me for the learning outcomes and exam format (quiz, midterm, discussion, etc.). If unknown, propose a reasonable set of outcomes and state assumptions.

Step 2 — Generate items
Produce 12 questions total:
- 4 recall/understand
- 4 apply/analyze
- 4 evaluate/create
Include answer keys or scoring guidance.

Step 3 — Improve
Check for clarity, bias, and accessibility (plain language, no trick wording). Revise and provide the final set.

Research Scoping (Search → Annotate → Synthesize)

Help me scope the literature on: [RESEARCH QUESTION].

Step 1 — Define scope
Ask 3–5 questions (time range, disciplines, populations, methodologies, key terms).

Step 2 — Gather
Provide a list of search strings and databases/venues to use. Then identify 8–12 likely relevant sources (with links) and write a 2–3 sentence annotation for each.

Step 3 — Synthesize
Group the sources into themes, summarize key findings, note gaps/controversies, and propose 3 next research directions.

Constraints:
- Clearly distinguish ‘found in sources’ vs ‘inference/suggestion’.
- Include links for each source.

Authentic Assessment (Reduce AI‑shortcut risk)

Act as a faculty assessment consultant. Redesign my assessment to be more authentic and resilient to AI shortcuts while still being fair and inclusive.

Inputs:
- Current assessment: [paste]
- Learning outcomes: [paste]
- Constraints (time, grading load, class size): [paste]

Step 1 — Diagnose
Identify where AI could easily generate an answer without learning.

Step 2 — Redesign
Propose 2 redesigned options (one low‑change, one high‑change) including instructions and submission requirements.

Step 3 — Safeguards
Add light‑touch integrity supports (process checkpoints, reflections, oral defense prompts, version history) and a student‑friendly AI‑use policy paragraph.
